Initial release of `@yak/solid`, the SolidJS runtime for yak, targeting Solid 2 (RC). Provides `styled`, `css`, `keyframes`, `globalStyle`, `atoms`, the css prop and a signal-based theme (`useTheme` returns an accessor) with build-time CSS extraction via the yak SWC plugin and `yak` from `@yak/solid/vite`.
