## The Roadmap

This list is not exhaustive and not ordered by priority. It is a rough outline of what we plan to work on next.

### Completed

- One package per framework in the `@yak` scope: `next-yak` becomes `@yak/react` (10.0)
- Plain CSS output for every bundler, which replaces CSS Modules and `:global()` (10.0)
- Solid 2 support with `@yak/solid` (experimental, see [Solid](/docs/solid))
- Rsbuild 2 support with the `next-yak/rsbuild` plugin, now `@yak/react/rsbuild` (next-yak 9.5.0)
- Storybook addon with Vite and webpack support (next-yak 9.1.0)
- Cross-file imports and `.yak` files across all bundlers (next-yak 9.4.0)
- Vite support, including Vite 8 with OXC/Rolldown (next-yak 9.1.0)
- Turbopack support (next-yak 8.0.0)
- Async RSC theme contexts (next-yak 8.0.0)

### Planned

- Qwik support with `@yak/qwik` (coming soon)
- More efficient runtime and code transformation
- Deduplicate styles
- More and better examples
