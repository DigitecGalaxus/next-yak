**next-yak** is a build-time CSS-in-JS library powered by a Rust SWC plugin. Write styled-components syntax, get zero-runtime CSS extraction and full React Server Components compatibility.

Works with **Next.js** (Webpack & Turbopack), **[Vite 7+](/docs/vite)** (react-router, tanstack start, and more), **[Rsbuild 2+](/docs/rsbuild)**, and **[Storybook](/docs/storybook)**.

| ------------------- | --------- | --------------- | --------------- | ----------- | -------- |
| `@yak/react` 10.x   | >= 16.4.0 | >= 7.0.0        | >= 2.0.0        | 19.x        | 79.0.0   |

Up to version 9, the package was called `next-yak`. From version 10, it is `@yak/react`. `@yak/react` 10 needs Node.js 22.18 or later. To move a project from `next-yak`, see [Migration from next-yak](/docs/migration-from-next-yak).

## Installation

<Steps>
<Step>

### Install the package

Install `@yak/react` with your package manager.

<Tabs title="Install @yak/react" items={['npm', 'pnpm', 'yarn', 'bun']}>
<Tab value="npm">
```bash
# For Next.js >= 16.4.0, Vite or Rsbuild
npm i @yak/react

# For Next.js 16.1 to 16.3 (for older versions, see the table above)
npm i next-yak@9
```
</Tab>
<Tab value="pnpm">
```bash
# For Next.js >= 16.4.0, Vite or Rsbuild
pnpm add @yak/react

# For Next.js 16.1 to 16.3 (for older versions, see the table above)
pnpm add next-yak@9
```
</Tab>
<Tab value="yarn">
```bash
# For Next.js >= 16.4.0, Vite or Rsbuild
yarn add @yak/react

# For Next.js 16.1 to 16.3 (for older versions, see the table above)
yarn add next-yak@9
```
</Tab>
<Tab value="bun">
```bash
# For Next.js >= 16.4.0, Vite or Rsbuild
bun add @yak/react

# For Next.js 16.1 to 16.3 (for older versions, see the table above)
bun add next-yak@9
```
</Tab>
</Tabs>
</Step>
<Step>

### Enable next-yak

Add next-yak to your configuration file:

<Tabs title="Enable next-yak" items={['next.config.ts', 'vite.config.ts']}>
<Tab value="next.config.ts">
```ts
import type { NextConfig } from 'next'
import { withYak } from "@yak/react/withYak";

const nextConfig: NextConfig = {
// your next.js config
}

export default withYak(nextConfig);
```
</Tab>
<Tab value="vite.config.ts">
```ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react-swc";
import { viteYak } from "@yak/react/vite";

export default defineConfig({
  //...
  plugins: [viteYak(), react()], // ideally this is before the react plugin
});
```
</Tab>

</Tabs>
</Step>
<Step>

### Start using next-yak

With the installation and configuration done, you can now use next-yak directly in your components.
If you used `styled-components` before, you'll feel right at home.

Here's a simple example:

```jsx title="app/page.tsx"
import { styled } from "@yak/react";

const StyledDiv = styled.div`
  color: #333;
  padding: 16px;
  background-color: #f0f0f0;
`;

export default function HomePage() {
  return <StyledDiv>Hello, next-yak!</StyledDiv>;
}
```

You're now ready to use next-yak in your project and if you need to migrate from styled-components, you can follow the [migration guide](/docs/migration-from-styled-components).

</Step>

</Steps>

## Using with Vite

Since v9.1.0, next-yak supports Vite 7+ (including Vite 8 with OXC/Rolldown). Check out the [Vite guide](/docs/vite) for more setup instructions.

## Using with Storybook

The addon `@yak/storybook` enables yak in Storybook 10+ with both Vite and Webpack builders. See the [Storybook guide](/docs/storybook) for details.
