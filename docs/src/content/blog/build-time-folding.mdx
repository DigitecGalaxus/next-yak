## What this post will cover

- The cost of a styled component: one extra component in the tree for each usage, on each render.
- Folding: when the compiler knows what a usage renders, it writes the DOM element directly.
- Static `css` props: the compiler turns them into a plain `className` string.
- When yak keeps the wrapper, and why that is correct.
- The runtime work for the cases that do not fold: the string class name collector and chain
  flattening.
- The numbers: every server rendering benchmark cell is faster than styled-components.
