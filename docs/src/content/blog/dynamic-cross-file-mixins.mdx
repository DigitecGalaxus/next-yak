## What this post will cover

- The problem: a mixin that reads props did not work when it came from another file.
- Why this is difficult: the compiler sees one file at a time, but the CSS must be static.
- How yak solves it: the cross-file resolver puts the mixin into the component that uses it.
- What now works: prop functions, nested mixins and mixins in selectors.
- What stays not supported.
