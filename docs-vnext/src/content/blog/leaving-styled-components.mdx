## What this post will cover

- Why teams leave styled-components now: maintenance mode, and no support for React Server
  Components.
- What stays the same: the `styled` and `css` syntax.
- What changes: dynamic styles become CSS variables, and some runtime patterns need a new form.
- How to move one file at a time, with both libraries in the same app.
- The tools that help: `eslint-plugin-yak` for ESLint and Oxlint, and `strictCssProp`.
- Global styles with `globalStyle`.
